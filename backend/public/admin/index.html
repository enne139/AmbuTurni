Repository formazione

Un solo link condiviso ai materiali di formazione dell'associazione (es. una cartella Drive): il tool "Repository formazione" nell'app lo apre direttamente nel browser.

Backup completo

Un unico archivio .zip con tutto ciò che questo backend conosce: ospedali, fogli turni, materiali, il link di formazione, gli account utente-app e i comunicati (PDF inclusi). Utile per spostare i dati su un'altra istanza o come copia di sicurezza prima di un intervento sul server.

Ripristina da backup

Carica un file generato da "Scarica backup completo" (qui o su un'altra istanza). Il ripristino aggiorna/aggiunge in base al contenuto del file — non cancella mai dati esistenti che non ci sono nel file.
